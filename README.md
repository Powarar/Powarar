## Featured Projects

### [News Radar](https://github.com/Powarar/news-radar)

Production news aggregation and personalization platform.

- Aggregates content from 35+ RSS feeds, websites, and Telegram channels
- Processes more than 45,000 collected news items
- Generates structured topic classifications and Russian summaries through Groq
- Uses Redis and Celery for parsing, AI processing, retries, and Telegram notifications
- Provides personalized feeds based on topic preferences, reactions, and freshness
- Includes JWT, Google OAuth and Telegram Mini App authentication
- Deployed with Docker, Nginx, GitHub Actions, PostgreSQL, Prometheus, Grafana, and Flower

[Live application](https://news.safonovpavel.space/feed)

### [FitMetrics](https://github.com/Powarar/FitMetrics)

Fitness tracking REST API built with asynchronous FastAPI.

- JWT authentication and PostgreSQL persistence
- Redis caching with pipeline-based operations
- ETL workflows using Apache Airflow
- Unit and integration test coverage
